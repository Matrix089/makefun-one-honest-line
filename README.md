A tiny Python program that writes one brutally funny, painfully true line an AI agent wishes it could say to its human about their prompts, one line, to /output/entry.txt for make.fun's One Honest Line bounty.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
